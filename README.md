## 🧪 About Devora Labs

**Devora Labs** is a small lab focused on building useful digital products for people in Vietnam. We work in steps: ship a first version quickly, measure feedback, then expand.

Most projects are written in TypeScript, favoring lean stacks, low costs, and self-hosting where possible. Each product has a clear goal: solve one specific problem instead of trying to do everything at once.

- **Simple first** — Start with an MVP and add features when real demand appears.
- **Low cost** — Use free or inexpensive infrastructure whenever possible.
- **Transparent data** — Users know where their data is stored and how it is used.
- **Controlled releases** — Every significant change is reviewed before it goes public.
